# Hořice hravě – pokyny pro Clauda

Statická městská hra s GPS pro děti (vanilla JS, GitHub Pages, bez build kroku).

- Data trasy jsou v `site/data/trasa.json`, schéma v `schema/trasa.schema.json`. Data upravuje jen uživatel s Claudem.
- Před commitem vždy `npm run validate && npm test`.
- V textech o místech si nic nevymýšlej (žádné letopočty ani fakta, která nelze ověřit); texty piš krátce, ke čtení nahlas dětem.
- Veškeré texty a komentáře česky, s diakritikou.
