# Hořice hravě – technický prototyp: implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Statická webová hra (GitHub Pages), která rodinu provede 3 zastaveními v Hořicích podle mapy a GPS a na každém odemkne úkol; s ukázkovým režimem pro předvádění u stolu.

**Architecture:** Statický web bez sestavování ve složce `site/` (HTML + CSS + ES moduly). Čistá logika (geo výpočty, stav hry, zdroj polohy) je v samostatných modulech testovaných `node --test`; UI je tenká vrstva nad nimi. Data trasy v `site/data/trasa.json`, validovaná JSON Schematem (ajv) jako v `clubs-horice`.

**Tech Stack:** HTML/CSS/vanilla JS (ES moduly), Leaflet 1.9.4 z unpkg, dlaždice Mapy.com REST API (záložně OSM), Node ≥ 18 (`node --test`, ajv), `http-server` pro lokální vývoj, GitHub Actions → GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-20-prototyp-design.md`

**Vzor:** `D:\work\_soukrome\clubs-horice` – struktura (`site/`, `schema/`, `scripts/validate.mjs`, `tests/`, `.github/workflows/deploy.yml` + `validate.yml`), styl kódu a češtiny. Kde plán něco neurčuje, dělej to jako tam.

## Global Constraints

- Žádný build krok, žádný framework, žádný backend. Jediná runtime knihovna: Leaflet `1.9.4` (`https://unpkg.com/leaflet@1.9.4/dist/leaflet.js` + `.css`).
- Veškeré texty pro uživatele česky, krátké, vhodné ke čtení nahlas dětem 5–10 let. Tlačítka velká (min. výška 48 px), čitelné na telefonu (šířka od 360 px).
- Fotky a poloha nikdy neopouštějí telefon.
- Repo: GitHub účet `SirotekC`, repozitář `horice-hra`, veřejný. Vytvoření repozitáře a push = **zeptat se uživatele** před provedením.
- Mapy.com: dlaždice `https://api.mapy.com/v1/maptiles/basic/256/{z}/{x}/{y}?apikey={KEY}`, atribuce `<a href="https://api.mapy.com/copyright" target="_blank">&copy; Seznam.cz a.s. a další</a>`, logo `https://api.mapy.com/img/api/logo.svg` odkazující na `https://mapy.com/` vlevo dole (povinné podle podmínek). Bez klíče záložně OSM `https://tile.openstreetmap.org/{z}/{x}/{y}.png` s atribucí `&copy; OpenStreetMap`.
- Poloměr automatického odemčení `30` m, poloměr záložního tlačítka „Jsme tady“ `80` m (hodnoty v `trasa.json`, ne v kódu).
- `.superpowers/` v `.gitignore`.

## Review Focus

1. **Uživatel zamítne polohu / GPS nedostupná** → hra nespadne, nabídne ukázkový režim (test: `poloha.test.mjs` – chyba GPS se předá do `onChyba`; ruční krok v Task 5).
2. **Obnovení stránky uprostřed hry** → pokračuje na stejném zastavení se zachovanými odpověďmi (test: `hra.test.mjs` – uložit/načíst).
3. **Ukázkový a GPS režim se nepletou** → postup z ukázky u stolu nesmí přeskočit zastavení při hře naostro (test: `hra.test.mjs` – různé klíče úložiště podle režimu).
4. **Nepřesná GPS (accuracy > 50 m)** → neodemykat automaticky jen kvůli přesnosti, zobrazit „GPS je teď nepřesná“ (test: `geo.test.mjs` – `stavPriblizeni` s velkou nepřesností).
5. **Prázdná odpověď / zrušené focení** → „Hotovo“ zůstane neaktivní, nic se neuloží (test: `hra.test.mjs` – prázdná odpověď je odmítnuta).

### Task 3: Stav hry a ukládání

**Files:**
- Create: `site/js/hra.js`
- Test: `tests/hra.test.mjs`

**Interfaces:**
- Consumes: struktura `trasa.json` (Task 1).
- Produces:
  - `novaHra(trasa): Stav` – `Stav = { trasaId: string, index: number, odpovedi: { [zastaveniId]: string } , dokonceno: boolean }`. `index` = aktuální zastavení (0-based).
  - `odpovez(stav, trasa, odpoved: string): Stav` – nový objekt (neměnit vstup); uloží odpověď k aktuálnímu zastavení a posune `index`; po posledním `dokonceno = true`. Prázdná / jen mezery odpověď → vyhodí `Error("Prázdná odpověď")`.
  - `aktualniZastaveni(stav, trasa): object | null` – `null` při `dokonceno`.
  - `klicUloziste(trasaId: string, demo: boolean): string` – `"horice-hra:" + trasaId + (demo ? ":demo" : "")`.
  - `uloz(uloziste: Storage-like, klic: string, stav): void`, `nacti(uloziste, klic, trasa): Stav | null` – vrátí `null`, když nic není, JSON je rozbitý nebo `trasaId` nesedí.

  - `nacti s rozbitým JSON vrátí null`; `nacti s jiným trasaId vrátí null`.

### Task 5: Herní obrazovky a mapa

**Files:**
- Create: `site/index.html`, `site/css/styl.css`, `site/js/app.js`, `site/js/mapa.js`, `site/js/config.js`, `site/favicon.svg`, `site/img/zastupny.svg`

**Interfaces:**
- Consumes: vše z Task 1–4.
- Produces:
  - `config.js`: `export const MAPY_API_KEY = "";` (prázdný = záložní OSM).
  - `mapa.js`: `vytvorMapu(element, { trasa, apiKey }): { ukazHrace(poloha: Poloha): void, ukazCil(zastaveni): void, onKlik(fn: (latlng) => void): void }` – Leaflet, čára trasy (oranžová přerušovaná), značky zastavení (splněná/aktuální/budoucí odlišené), modrá tečka hráče s kruhem přesnosti, mapa se při prvním zobrazení přizpůsobí trase.

Obrazovky (jedna stránka, přepínání sekcí; podle odsouhlaseného náčrtu, viz spec „Průběh hry“):
1. **Úvod** – název, `pro_koho`, „3 zastavení · ~1,5 km · ~1 h“, `poznamka_pro_rodice`; tlačítka „Vyrazit“ (ostrá GPS) a menší „Ukázka u stolu“. Pokud existuje uložený postup → „Pokračovat“ + „Začít znovu“.
2. **Mapa** – horní lišta „Zastavení X/3“ + „⭐ N“; mapa; spodní karta s názvem cíle a `formatVzdalenost`. Při `blizko` tlačítko „Jsme tady“. Při přesnosti > 50 m hláška „GPS je teď nepřesná, chvilku počkejte.“ V ukázkovém režimu fialový štítek „Ukázkový režim“ a tlačítka „Dojít k dalšímu zastavení“ (`jdiK`) a klepnutí do mapy přesune hráče (`nastav`).
3. **Na místě** – obrázek (`obrazek` nebo `img/zastupny.svg`), `nazev`, `text`, „Otevřít úkol“. Zobrazí se automaticky při `na-miste` nebo po „Jsme tady“.
4. **Úkol** – `zadani`; podle typu: `cislo` → `<input inputmode="numeric">` velkým písmem; `foto` → `<input type="file" accept="image/*" capture="environment">` + náhled (`URL.createObjectURL`, uchovat v paměti pro konec); `text` → `<textarea>`. „Nápověda“ ukáže `napoveda`. „Hotovo“ neaktivní, dokud není odpověď/fotka. Po „Hotovo“ → `odpovez` → `uloz` → zpět na mapu nebo na konec.
5. **Konec** – „Hotovo, objevitelé!“, hvězdy N/3, náhledy fotek z tohoto sezení (po obnovení stránky nemusí být), poznámka „Diplom nebo odměna v infocentru – připravujeme“, „Hrát znovu“.

Ostatní chování:
- Ukázkový režim i přes URL `?demo=1`; simulace startuje 150 m před prvním zastavením na čáře (stačí první bod `cara` posunutý; přesné místo na tobě).
- `onChyba` → hláška „Polohu se nepodařilo zjistit…“ + tlačítko „Přepnout na ukázku“.
- Upozornění na bezpečnost na mapě (malý řádek): „Při chůzi se dívejte kolem sebe, ne do telefonu.“
- Barvy převezmi z odsouhlaseného náčrtu: zelená `#2f6b4f` (lišta), oranžová `#e8892b` (hlavní tlačítko, trasa), pozadí `#f6f3ea`, fialová `#7b3fa0` (ukázkový režim).
